# Prática de Limpeza e Análise Exploratória de Dados
Este projeto apresenta um processo completo de Análise Exploratória de Dados (EDA) utilizando um conjunto de dados contábeis fictícios. O foco é demonstrar, de forma prática, como investigar a qualidade dos dados, identificar inconsistências e aplicar técnicas de limpeza e tratamento antes de avançar para etapas analíticas ou modelos estatísticos.

## Objetivo do Projeto
O objetivo principal é:
* Explorar e compreender o comportamento das variáveis do dataset.
* Comparar visualmente os dados antes e depois da limpeza.
* Demonstrar técnicas comuns de tratamento de dados utilizados em projetos reais.
* Criar uma base limpa, confiável e pronta para análises futuras.

### Análise Exploratória (EDA)
Foram aplicadas técnicas iniciais de investigação do dataset, incluindo:
* Visualização da distribuição das variáveis.
* Detecção de assimetria (skewness).
* Estatísticas descritivas.
* Identificação de padrões incomuns.

📈 Gráficos utilizados:
* Histogramas
* Boxplots
* Scatterplots (quando aplicável)
Os gráficos foram gerados antes e depois da limpeza para facilitar a comparação dos efeitos do tratamento de dados.

### Processo de Limpeza dos Dados
O dataset passou por várias etapas de higienização:
* Remoção de valores negativos
* Checagem de registros duplicados
* Tratamento de valores nulos
* Detecção e tratamento de outliers de acordo com o contexto

### Comparação Antes x Depois
Após o tratamento, os gráficos foram ref feitos mostrando como:
* A distribuição se tornou menos assimétrica
* Reduziu-se o impacto de outliers que eram erros
* A variabilidade das variáveis mudou
* O dataset ganhou mais consistência de acordo com que foi pedido a ser feito
* Depois de limpeza tornou-se melhor de visualizar a distribuição das variáveis
